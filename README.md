# Portfolio Fotográfico — Guillermo Álvarez

Sitio web completo para un fotógrafo profesional en CDMX.

🔗 [Ver sitio en vivo](https://guillermoworks.com)

## Stack
- HTML5 / CSS3 (sistema de diseño con custom properties, dark/light mode)
- JavaScript vanilla (sin frameworks)
- PHP + MySQL (backend de formularios)
- i18n propio (ES/EN)

## Features destacadas
- Galería con auto-scroll y control por drag (Pointer Events API)
- Sistema de internacionalización con JSON
- Seguridad: rate limiting, honeypot, variables de entorno
- Formularios con validación y almacenamiento en base de datos
